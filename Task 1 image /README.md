# CodeAlpha Task 1 — Image Gallery

## Features
- Responsive HTML/CSS gallery
- JavaScript next/previous navigation
- Full-screen lightbox preview
- Keyboard support: Left, Right and Escape
- Smooth hover and transition effects
- Responsive layout for mobile, tablet and desktop
- Bonus category filters: All, Nature, Travel and City

## How to run
1. Open `index.html` in a browser.
2. Click an image to open the lightbox.
3. Use the arrows or keyboard arrows to navigate.
4. Use the category buttons to filter images.

The gallery uses Unsplash image URLs, so an internet connection is needed for the images.
