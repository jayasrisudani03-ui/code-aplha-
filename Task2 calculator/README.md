# CodeAlpha Task 2 — Calculator

## Features
- Basic calculator using HTML, CSS and JavaScript
- Addition, subtraction, multiplication and division
- Percentage operation
- Clear and delete controls
- Real-time display
- Division-by-zero handling
- Keyboard support
- Responsive design for mobile and desktop
- Light/dark theme toggle

## How to run
1. Open `index.html` in a browser.
2. Use the buttons or your keyboard to perform calculations.
3. Press `Enter` for `=`, `Backspace` for delete and `Esc` for clear.
4. Click the moon/sun button to change the theme.
